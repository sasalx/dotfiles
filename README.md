# dotfiles

Personal configuration files, managed with [nina](https://github.com/sasalx/nina) for symlinking.

## Contents

- `config/zsh/.zshrc` — Zsh shell configuration
- `config/starship/starship.toml` — Starship prompt configuration
- `config/vesktop/settings.json` — Vesktop settings

## Usage

Symlinks are defined in `nina.yaml`. Install [nina](https://github.com/sasalx/nina), then run it from this repo to link the files into place.
